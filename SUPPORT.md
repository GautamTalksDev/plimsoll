# Support

## Questions and bugs

Open a GitHub issue on this repository.

This project does not run evaluations and does not accept datasets, models,
prompts, or outputs. Do not attach eval data to issues. Digests and metadata
only.

## What we will not help with

- Choosing, designing, or running an evaluation
- Interpreting a quality metric or score
- Overriding a sealed decision rule

See [docs/NON-GOALS.md](docs/NON-GOALS.md).

## Security

See [SECURITY.md](SECURITY.md). Do not report vulnerabilities in public issues.
